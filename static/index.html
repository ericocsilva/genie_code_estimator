Sizing rápido de Genie Code

Quatro perguntas para uma ordem de grandeza do custo do projeto. Para o número final, use o Deep dive.

1 Quantas pessoas vão usar Genie Code no projeto?
2 Como o time vai usar o Genie Code no dia a dia?
3 Por quanto tempo? (duração do projeto)
4 Haverá automações (jobs ou agentes via service principal) usando Genie Code?
Service principals não têm free tier. Premissa: cada fluxo consome como um super power user.
